# libopc

[![CMake](https://github.com/wissem01chiha/libopc/actions/workflows/cmake.yml/badge.svg)](https://github.com/wissem01chiha/libopc/actions/workflows/cmake.yml)
[![CodeFactor](https://www.codefactor.io/repository/github/wissem01chiha/libopc/badge)](https://www.codefactor.io/repository/github/wissem01chiha/libopc)


A C99 library for processing [ISO/IEC 29500-2](https://www.iso.org/standard/77818.html) (Open Packaging Conventions) files, Originally developed by [Florian Reuter](https://github.com/freuter).

Visit the [libopc project](https://wissem01chiha.github.io/libopc/) page for distribution tarballs and additional information.
